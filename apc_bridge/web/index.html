Titan Go setup

For every fader and every mapped button: in Titan Go open System → Triggers, add a trigger, Type Item, choose the playback, action Set Level, source Streaming ACN, universe and channel as set here. Or turn Learn On in Titan, switch output ON here and use the control once.

Momentary buttons send their ON level while held (flash). Toggle buttons latch. A button sends its OFF level whenever it is not on, so Titan follows it both ways.
